# BL_Flatform

견해 모듈(`Module_Based_ML`)이 만든 월별 투자자 견해(P·Q·Ω)를 Black-Litterman 모형에 넣어 20종목 포트폴리오를 최적화하고,
2019~2020년 24개월 월간 백테스팅 결과를 보여주는 **단일 HTML 도구**입니다.

`framework-main`(Streamlit 앱)의 화면 구성과 BL 식을 그대로 옮겼고, 월별 대시보드를 더했습니다.
두 폴더의 차이는 [README_framework_비교.md](README_framework_비교.md)에 정리되어 있습니다.

## 실행

**`index.html`을 더블클릭**하면 됩니다. 서버·Python·인터넷이 필요 없고, 모듈 결과가 미리 들어 있어 파일을 업로드할 필요도 없습니다.

1. 왼쪽 사이드바에서 **견해 모듈**(상준 · ANN / 상준 · ElasticNet / 근석 · XGBoost)과 **기간**(P1 / P2)을 고릅니다.
2. 파라미터를 조정합니다.
   - **1. 거시 변수**: λ, τ, 무위험수익률
   - **2. 사전분포**: 사전분포 가중치(동일가중 / 시장 가중치), Σ 추정(롤링 / 고정)
   - **3. 최적화 및 불확실성**: Ω 방식, 공매도 허용, 종목당 최대 비중, 거래비용
3. **✅ 적용** 버튼(또는 숫자 칸에서 Enter)을 누르면 모든 탭이 다시 계산됩니다. 누르기 전에는 결과가 바뀌지 않습니다.
4. 사이드바 맨 위 **☀️ / 🌙** 버튼으로 라이트·다크 테마를 바꿉니다 (기본: 다크, 브라우저에 기억됨).

## 계산 방식

### 견해와 수익률 기간 맞추기
- **날짜로 맞춥니다.** 견해 날짜(월말)의 P·Q·Ω로 BL을 풀고, 그 비중을 **다음 달** 한 달 동안 보유해 그 달의 실현수익률로 평가합니다.
  - 2018-12-31 견해 → 2019년 1월 수익률, …, 2020-11-30 견해 → 2020년 12월 수익률 (총 24개월)
- 견해 행의 순서나 수익률 파일의 시작 월과 상관없이 날짜로 짝을 짓습니다. 그래서 중간에 견해가 빠진 달이 있어도 **그 달만 빠지고** 나머지 달은 밀리지 않습니다.
- 견해 날짜가 주가 데이터 기간 밖이거나 다음 달 수익률이 없으면, 그 견해는 건너뛰고 경고를 띄웁니다.
- Q = 0인 견해도 "초과수익 없음"이라는 정상 견해로 반영합니다.

### 같은 날짜의 견해가 여러 개일 때
- 같은 날짜의 견해 K개를 **하나로 묶어(P: K×N, Q: K개, Ω: K×K 대각) BL을 한 번에** 풉니다.
- 견해끼리의 공분산(PτΣPᵀ의 비대각 원소)이 반영되므로, 겹치는 견해는 덜 반영되고 서로 반대인 견해는 절충됩니다.
- 현재 세 모듈은 모두 한 달에 견해가 1개(K = 1)입니다. 새 모듈이 한 달에 여러 견해를 내도 그대로 처리됩니다.

### BL 식 (`framework-main/bl_engine.py`와 같은 식)
- **사전분포**: Π = λΣw. 사이드바 **2. 사전분포**에서 고릅니다.
  - 동일가중 (기본)
  - 시장 가중치 w_mkt (framework-main 방식): 탭 1에 올린 `Asset, MarketWeight` CSV를 씁니다. Project_Data에는 발행주식수가 없어 시가총액을 직접 계산할 수 없으므로 CSV로 넣어야 합니다. CSV가 없으면 동일가중으로 계산하고 경고를 띄웁니다.
  - 사전분포 포트폴리오가 곧 백테스팅 비교 벤치마크입니다.
- **Σ**: 사이드바 **2. 사전분포**에서 고릅니다.
  - 롤링 (기본): 견해 날짜까지 최근 60개월 월간 수익률의 표본공분산 (매월 재추정, 미래 정보 없음).
  - 고정 (framework-main 방식): 탭 1에 올린 Σ를 모든 달에 씁니다. 없으면 첫 견해 날짜까지 최근 60개월로 한 번 추정해 씁니다.
- 탭 1에서 가중치나 Σ CSV를 올리면 해당 설정이 자동으로 framework 방식으로 바뀝니다.
- **Ω**: 기본은 모듈이 제공한 값(`Omega.csv`). 신뢰도 기반((1−C)/C · τPΣPᵀ) 또는 He & Litterman(τPΣPᵀ)으로 바꿀 수 있습니다.
- **사후분포**: μ_BL = Π + τΣPᵀ(PτΣPᵀ + Ω)⁻¹(Q − PΠ), Σ_BL = Σ + M
- **최적화**: max wᵀμ_BL − (λ/2)wᵀΣ_BL w, Σw = 1, 롱온리(기본), 종목당 최대 비중(기본 20%, 모듈 `constraints.json` 값).
- **거래비용**: 편도 비용률(0.1%) × 매매 회전율을 월 수익률에서 차감합니다. BL과 사전분포 포트폴리오 모두에 적용합니다.

### 해석할 때 주의
- 평가 구간이 24개월로 짧아 성과 차이가 통계적으로 유의하지 않을 수 있습니다.
- 20종목은 2018년까지의 데이터로 골랐고 2020년까지 살아남은 종목이라 생존편향이 있을 수 있습니다.
- 모듈마다 Q의 크기가 크게 다릅니다 (예: ANN은 Q를 크게 잡음). Ω·τ 설정에 따라 견해가 반영되는 정도가 달라집니다.

## 다시 만들기

견해 모듈 결과가 바뀌거나, 새 모듈을 추가했거나, `template.html`·`engine.js`를 고쳤을 때 실행합니다.

```bash
pip install numpy pandas plotly
python build_platform.py
```

- `Module_Based_ML/` 아래의 모든 `<모델>/<P1|P2>/bl_input/` 폴더를 자동으로 찾습니다 (zip 안에 있어도 됨).
- 필수 파일: `assets.csv`, `P.csv`, `Q.csv`, `Omega.csv`
- 선택 파일: `confidence.csv`, `constraints.json`, `../diagnostics/predicted_returns.csv`
- `bl_input`이 없는 모듈 폴더(현재 XGBoost(현주))는 사이드바에 비활성으로 표시됩니다. 같은 형식으로 결과를 저장한 뒤 다시 실행하면 자동으로 추가됩니다.
- 필요한 데이터가 모두 이 폴더 안에 있으므로 `BL_Platform` 폴더만 옮겨도 다시 만들 수 있습니다.
